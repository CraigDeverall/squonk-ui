# Working on @squonkstack/ui

This repository is `@squonkstack/ui`, Squonk's React 19 component library, plus
`packages/ui-mcp` (`@squonkstack/ui-mcp`), the MCP server and setup command that
connect coding agents in consuming apps to it. These instructions are for
agents changing the library. Agents building apps with it read
`skills/use-squonk-ui/SKILL.md`, which ships in the package.

## Before you change anything

- Read `.claude/skills/README.md`. It routes each kind of request to the
  repository's skills in `.claude/skills/`; read only the ones the task needs.
- Sources of truth: `DESIGN_SYSTEM.md` (principles and compatibility),
  `REVIEW_GUIDE.md` (must-fix rules), `src/design-system/design-system.mdx`
  (foundations and supported compositions), `src/theme/` (tokens).
- React Aria Components is the base for every component it has a primitive for.
  TanStack Table handles table data, TanStack Form with Zod handles forms, and
  styles are CSS Modules bound to purpose tokens (`--squonk-roles-*`,
  `--squonk-components-*`), never raw scale steps or literals.

## Rules that are easy to miss

- A change that adds, renames or removes a public component, prop or pattern
  also updates `skills/use-squonk-ui/SKILL.md` and the catalog
  (`npm run catalog:generate`) in the same pull request.
- Public props carry JSDoc: agents in consuming apps learn the API from the
  shipped `.d.ts` files.
- `src/index.ts` and the `package.json` exports are public API. Run the
  `non-breaking-refactor` skill before changing them; exports are generated by
  `scripts/generate-package-exports.mjs`.
- Commits follow Conventional Commits (commitlint enforces it). semantic-release
  publishes `@squonkstack/ui` and `@squonkstack/ui-mcp` together at one version to npm,
  tags it and creates a GitHub Release; it commits nothing to `main`. Leave
  `0.0.0-development` in `package.json` and don't add to `CHANGELOG.md`.
- The repository is GitHub `CraigDeverall/squonk-ui`. Never push to `main`: open
  a pull request and merge it (a merge commit) only after its checks pass. Every
  commit on the branch lands as is, so each needs the right type.
- `npm test` runs the Playwright component tests in Docker. Only one project
  stack may run in local Docker Desktop at a time; check before starting it.

## Checks

Use the Node version in `.nvmrc`. Run what the change touches:
`npm run typecheck`, `npm run lint`, `npm run test:unit`, `npm run test:scripts`,
`npm run catalog:check`, `npm run build`, and for the MCP package
`npm run typecheck -w @squonkstack/ui-mcp`, `npm test -w @squonkstack/ui-mcp` and
`npm run test:e2e -w @squonkstack/ui-mcp`. Report what you checked and how, kept
separate: source read, static checks, behaviour exercised in a browser,
screenshots reviewed.
