# Changelog

Release notes for each version are published on
[GitHub Releases](https://github.com/CraigDeverall/squonk-ui/releases).

## Initial open-source release

First public release of `@squonkstack/ui`, Squonk's React 19 component library, and
`@squonkstack/ui-mcp`, the MCP server and setup command that connect coding agents
to it. Both packages are published to the public npm registry under the MIT
licence.
