# Illustration

Small spot illustrations for the moments a screen needs a picture: an empty
list, a search with no results, a step finished, a feature on a landing page.
They're drawn in one style (ink outlines, paper and tint fills, one accent
touch), and every colour comes from the theme, so they follow your brand and
the colour mode with no extra work.

```tsx
import { InboxIllustration } from "@squonkstack/ui/illustration";

<EmptyState
  icon={<InboxIllustration size="lg" />}
  title="No sightings yet"
  body="Sightings you log will appear here."
/>
```

## The set

Each illustration is its own component, named for what it means, so import only
the ones you use. `ILLUSTRATIONS` maps every name to its component, for
galleries and pickers; importing it brings in every drawing. The tables group
them by the moment they suit.

## Sizes

`size` takes `sm` (48px), `md` (64px, the default), `lg` (96px) or `xl`
(128px), from the theme's `components.illustration.size.*` tokens.

## Theming

Illustrations bind to component tokens that point at the shared roles, so they
change with the theme and nothing else:

| Token | Default | What it colours |
| --- | --- | --- |
| `components.illustration.ink` | `roles.color.text` | Outlines and the darkest marks |
| `components.illustration.paper` | `roles.color.surface` | Pages, windows and cards |
| `components.illustration.accent` | `roles.color.accent` | The one brand touch |
| `components.illustration.onAccent` | `roles.color.onAccent` | Marks drawn on the accent |
| `components.illustration.tintStrength` | `32%` | How much accent is mixed into the tint fill |
| `components.illustration.stroke` | `1.75` | Outline width, in units of the 48-unit drawing |

The tint is mixed on each illustration, so one inside a `ThemeModifier` or a
dark section takes that scope's colours. Switch the theme or the mode in the
toolbar to see the set follow.

## Accessibility

- Most illustrations repeat what the heading or message beside them says. Leave
  `label` out and the illustration is hidden from assistive technology.
- When the picture carries meaning nothing else says, give it a `label`: it
  becomes an image with that name.
- Never put the only instruction or status in an illustration; say it in text.

## Common pitfalls

- **Using an illustration as an icon.** Icons sit inside controls and lines of
  text; illustrations sit beside content. Use `Icon` components in buttons,
  fields and menus.
- **Recolouring with CSS.** Re-point the `components.illustration.*` tokens (or
  the roles they follow) instead, so every illustration changes together.
- **Importing `ILLUSTRATIONS` for one picture.** It brings in every drawing;
  import the named component.
