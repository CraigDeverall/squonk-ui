# Breadcrumb

<ResizableCanvas of={BreadcrumbStories.Default} defaultHeight={100} />

`Breadcrumb` shows where the current page sits in the site's hierarchy and links
back up it. It helps on deep, structured sites (membership → chapter → sightings →
one sighting). It is not a history of where someone has been, and it doesn't
replace the main navigation.

```tsx
import { Breadcrumb } from "@squonkstack/ui/breadcrumb";
import NextLink from "next/link";

<Breadcrumb
  linkAs={NextLink}
  items={[
    { label: "My account", href: "/account" },
    { label: "Sightings", href: "/sightings" },
    { label: "Sighting of 14 March 2026" },
  ]}
/>
```

<Controls />

## Router links

`linkAs` sets the component each crumb renders as, so client-side routing works.
It receives `href`, `className` and the children.

## Home icon

`homeIcon` replaces the first crumb's text with a home icon. The text stays as the
link's accessible name.

<ResizableCanvas of={BreadcrumbStories.HomeIcon} defaultHeight={100} />

## Long trails

`maxItems` keeps the first crumb and the last `maxItems - 1`, and puts a "…"
button in between. Pressing it reveals the rest and moves focus to the first
revealed crumb.

<ResizableCanvas of={BreadcrumbStories.Collapsed} defaultHeight={100} />

## Long names

Each crumb is cut off with an ellipsis after about 24 characters (40 for the
current page), and the trail wraps onto more lines rather than overflowing.

<ResizableCanvas of={BreadcrumbStories.LongNames} defaultHeight={140} />

## With the page heading

Place it above the page's `h1`. The current page is the last crumb and the
heading repeats it.

<ResizableCanvas of={BreadcrumbStories.PageHeader} defaultHeight={160} />

## Accessibility

- A `nav` landmark named "Breadcrumb" (change it with `aria-label`) holding an
  ordered list, so screen readers announce "list, 4 items".
- The current page is the last item, not a link, and has `aria-current="page"`.
- The chevrons between crumbs are decorative and hidden from assistive technology.

## Common pitfalls

- **Don't link the current page.** A link to where you already are is a dead end.
- **Don't use a breadcrumb on a flat site.** With one or two levels it is noise.
- **Don't build the trail from browser history.** It shows hierarchy, not the path
  someone took.
