# CheckboxGroup

<ResizableCanvas of={CheckboxGroupStories.Default} defaultHeight={340} />

`CheckboxGroup` asks one question with several independent answers: "Which
accounts do you want to set up?". It keeps the selection as an array of values,
names the group with a legend, and puts group-level errors in one place.

```tsx
import { CheckboxGroup } from "@squonk/ui/checkbox-group";

<CheckboxGroup
  legend="Which accounts do you want to set up?"
  name="accounts"
  options={[
    { value: "dues", label: "Annual dues" },
    { value: "levy", label: "Swamp Fund levy" },
  ]}
  value={accounts}
  onChange={setAccounts}
/>
```

Use `RadioGroup` when only one answer is allowed, and a single `Checkbox` for one
yes/no question ("I agree to the terms").

## In a row

Short options can sit in a row. Keep to two to four, and keep them short; long
labels wrap awkwardly.

## Accessibility

- A `<fieldset>` named by its legend; helper and error text are its description.
  Each option's own `helperText` describes that checkbox.
- Each option is a native checkbox: Tab moves between them and Space toggles.
- Every checked option submits its `value` under the shared `name`.

## Common pitfalls

- **Don't use a CheckboxGroup for "pick one".** Checkboxes signal that several
  answers are allowed. Use `RadioGroup`.
- **Don't use a CheckboxGroup for settings that apply immediately.** Use `Switch`es.
- **Don't hide why an option is disabled.** Give it `helperText`.
