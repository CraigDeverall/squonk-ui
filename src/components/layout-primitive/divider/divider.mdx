# Divider

<ResizableCanvas
  of={DividerStories.Horizontal}
  defaultRecipe="centered"
  defaultHeight={80}
/>

A semantic separator between sibling content. `Divider` renders a native `<hr>` for horizontal lines (the accessible default) and switches to a `<div>` with `role="separator"` and `aria-orientation="vertical"` for vertical ones — `<hr>` has no vertical mode.

<Controls />

## Horizontal

The standard "between sections" use.

<InlineCodeExample>
  <Block width="320px">
    <VStack gap="sm">
      <Text>About</Text>
      <Divider />
      <Text>Contact</Text>
      <Divider />
      <Text>Privacy</Text>
    </VStack>
  </Block>
</InlineCodeExample>

## Vertical

Drop into an inline `HStack` to break up a row of items — breadcrumbs, metadata strips, toolbar groups.

<InlineCodeExample>
  <HStack gap="sm" align="center">
    <Text>Home</Text>
    <Divider orientation="vertical" />
    <Text>Projects</Text>
    <Divider orientation="vertical" />
    <Text>checkout-flow</Text>
  </HStack>
</InlineCodeExample>

## In a card

A horizontal divider works well between card sections — title vs body, body vs footer.

<InlineCodeExample>
  <Block padding="md" radius="base" bordered>
    <VStack gap="sm">
      <Text weight="bold">Settings</Text>
      <Divider />
      <Text>Update your workspace name, billing, and team members.</Text>
      <Divider />
      <a href="#">Delete workspace</a>
    </VStack>
  </Block>
</InlineCodeExample>

## Accessibility

- The horizontal variant uses `<hr>`, which assistive tech already announces as a separator — no ARIA needed.
- The vertical variant adds `role="separator"` and `aria-orientation="vertical"` so it remains announced after the element change.
- The divider color uses `theme.colors.border.default` — verified to meet WCAG AA contrast against both light and dark backgrounds without being visually loud.

## Common pitfalls

- **Don't use Divider for decoration.** If the line isn't meaningfully separating content, it's just visual noise — drop it.
- **Vertical dividers need a sized flex parent.** Without one (e.g. `align="stretch"` on an `HStack`), there's no height for the line to take.
- **Don't put a divider above the page footer.** `Footer` already has its own top border; adding a divider creates a double line.
- **Don't pile up dividers between every list item.** That's a `<ul>` with row gaps and (optionally) hover states — not a stack of Dividers.
