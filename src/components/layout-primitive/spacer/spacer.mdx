# Spacer

<ResizableCanvas of={SpacerStories.PushApart} defaultRecipe="stack-right" />

`Spacer` consumes leftover space inside a flex parent — typically used to push two groups of siblings to opposite ends of a row. Use `HStack` with `justify="between"` (or the `Split` named composition) when you can; reach for `Spacer` only when the split isn't symmetric or you need it between specific siblings. `size="auto"` grows; any other token sets a fixed dimension and acts as a structural gap (useful in non-flex contexts).

<Controls />

## Push to the edge

The classic — push the trailing item to the end of the row.

<InlineCodeExample>
  {`<HStack align="center">
  <Logo />
  <NavLinks />
  <Spacer />
  <UserMenu />
</HStack>`}
</InlineCodeExample>

## Fixed-size gap

For a deliberate gap between specific siblings in a row, set a token size.

<InlineCodeExample>
  {`<HStack align="center">
  <Button>Back</Button>
  <Spacer size="lg" />
  <Button>Next</Button>
</HStack>`}
</InlineCodeExample>

## Asymmetric split

For three groups where only the middle gap should grow — neither `justify="between"` nor `Split` handles this cleanly.

<InlineCodeExample>
  {`<HStack>
  <Brand />
  <Nav />
  <Spacer />
  <UserMenu />
</HStack>`}
</InlineCodeExample>

## Accessibility

- Renders `aria-hidden="true"` — it has no semantic content for assistive tech.
- Doesn't affect focus or tab order.

## Common pitfalls

- **Prefer `HStack justify="between"` (or `Split`) for the symmetric two-group case.** Spacer is for when there are three+ siblings and only one of the gaps should grow.
- **Doesn't work outside a flex parent when `size="auto"`.** Either set a token size or put it inside an `HStack` / `VStack`.
- **Don't sprinkle Spacers between every child.** That's what `gap` is for — Spacer is for *uneven* gaps.
- **Don't use Spacer to add vertical space between sections.** Use the parent `VStack`'s `gap` or pad the section directly.
