# VStack

<ResizableCanvas of={VStackStories.Default} />

`VStack` arranges its children vertically (top to bottom) with a token-driven gap and sensible alignment props. It is **not** a styled container — no padding, border, or background, only arrangement. For horizontal arrangement use `HStack`; for two-dimensional layouts use `Grid`.

<Controls />

## Default

The basic use — a column of items with consistent gap.

<InlineCodeExample>
  {`<VStack gap="md">
  <Card>One</Card>
  <Card>Two</Card>
  <Card>Three</Card>
</VStack>`}
</InlineCodeExample>

## Centering

A `VStack` with `align="center"` and `justify="center"` centers its child on both axes — though for a single centered child, `Centered` is more declarative.

<InlineCodeExample>
  {`<VStack align="center" justify="center" style={{ minHeight: 240 }}>
  <Card>I am centered.</Card>
</VStack>`}
</InlineCodeExample>

## Space between

Push the first child to the top and the last to the bottom with `justify="between"`.

<InlineCodeExample>
  {`<VStack justify="between" style={{ minHeight: 200 }}>
  <Heading>Title</Heading>
  <Button>Action at the bottom</Button>
</VStack>`}
</InlineCodeExample>

## Tighter gap

For typography stacks (heading + body + meta), a tighter `xs` / `sm` gap reads better than the default `md`.

<InlineCodeExample>
  {`<VStack gap="xs">
  <Heading level={4}>checkout-flow</Heading>
  <Text tone="secondary">Production traffic from web and mobile.</Text>
  <Text tone="muted">Last deployed 4 hours ago</Text>
</VStack>`}
</InlineCodeExample>

## Accessibility

- Renders a plain `<div>` — no roles, no announcements. Children supply their own semantics.
- DOM order is reading order; flex `justify` doesn't change traversal.
- For a list of equivalent items, render as `<ul>` (`as="ul"`) and wrap children in `<li>` so screen readers announce the count.

## Common pitfalls

- **Don't add margins to children.** The whole point of VStack is that the parent owns the spacing. If you find yourself reaching for `margin-top` on a child, change the `gap` instead.
- **`align="stretch"` is the default.** Children fill the cross-axis (full width). Switch to `align="start"` if you want them to size to their content.
- **Need horizontal arrangement?** Use `HStack` — they are peer components, not variants of one another.
- **Don't reach for VStack for a single centered child.** `Centered` exists for exactly that — using a VStack with `align="center" justify="center"` and `minHeight` is the long way around.
