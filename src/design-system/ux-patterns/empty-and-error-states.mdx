# Empty and error states

An empty screen is a message. First use, no matches, no access and a failed load
each mean something different, so each needs its own words and its own next
step. Compose [EmptyState](?path=/docs/layout-empty-state--docs) with a
[Button](?path=/docs/functional-button--docs) or [Link](?path=/docs/functional-link--docs).

<Example caption="First use, no matches and a failed load. “Create”, “Clear search” and “Try again” are not interchangeable.">

</Example>

## The rules

- **Say what happened, then the next useful step.** Keep the title short.
- **Never show a failed load as “nothing here”.** It tells people their records
  are gone.
- **Keep what's already on screen during a refresh.** Show the empty state only
  once you know there's nothing.
- **Fit the space.** In a small card or table, drop the icon and use one action.
  Pass it to [Table](?path=/docs/functional-table--docs) as `empty`.
